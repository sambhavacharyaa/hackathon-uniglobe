{% comment %} Live diagnosis demo. The centrepiece. Picking a student replays their attempt stream and then assembles a diagnosis card, with the cited attempts highlighted in place on the left. That link between claim and evidence is what makes the feature read as analysis rather than a guess, so it is the one interaction the section is built around. The first student is rendered server-side in full, so the panel is complete and readable before a single byte of JavaScript executes. The script only ever re-renders what is already there. This runs entirely on the client against seeded data — labelled as a simulation in the UI, because claiming a live model call on a marketing page that does not make one would be a lie a judge could catch in devtools. {% endcomment %}
